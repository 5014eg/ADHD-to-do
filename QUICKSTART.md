# Инструкция по запуску ADHD To-Do List

## 🚀 Быстрый старт

### 1. Установка Node.js (если не установлен)

1. Перейдите на https://nodejs.org/
2. Скачайте **LTS версию** (рекомендуется)
3. Запустите установщик и следуйте инструкциям
4. После установки перезапустите PowerShell/терминал

### 2. Проверка установки

Откройте PowerShell и выполните:

```powershell
node --version
npm --version
```

Должны появиться версии (например, v20.x.x и 10.x.x)

### 3. Установка зависимостей проекта

```powershell
cd "c:\Users\v0v\OneDrive\Desktop\simple ADHD To-Do List"
npm install
```

Это займёт 1-2 минуты.

### 4. Запуск приложения

```powershell
npm start
```

Приложение автоматически откроется в браузере на http://localhost:8080

## 📱 Тестирование на телефоне

### Вариант 1: Через локальную сеть

1. Узнайте ваш локальный IP:
   ```powershell
   ipconfig
   ```
   Найдите строку `IPv4 Address` (например, 192.168.1.100)

2. На телефоне откройте браузер и введите:
   ```
   http://192.168.1.100:8080
   ```

## ❓ Troubleshooting

### Ошибка: "npm: The term 'npm' is not recognized"

**Решение:** Node.js не установлен или не в PATH
1. Переустановите Node.js
2. Перезапустите PowerShell
3. Проверьте: `node --version`

### Ошибка при npm install

**Решение:** Удалите старые зависимости и переустановите
```powershell
Remove-Item -Recurse -Force node_modules
Remove-Item package-lock.json
npm install
```

### Приложение не открывается автоматически

**Решение:** Откройте вручную
- Перейдите в браузере на http://localhost:8080

### Drag-and-drop не работает на телефоне

**Решение:** 
- Нужно долго нажимать (200ms) перед перетаскиванием
- Убедитесь, что используете современный браузер (Chrome/Safari)

## 🎯 Как пользоваться приложением

### Создание задачи:
1. Нажмите на **цветной квадрат** → выберите категорию
2. Введите **текст задачи**
3. Нажмите **+**

### Планирование на день:
1. Возьмите задачу из пула (за иконку ⋮⋮)
2. Перетащите на нужный день недели
3. Отпустите

### Возврат в пул:
- Перетащите задачу обратно на **"📋 Пул задач"**

### Отметка выполнения:
- Нажмите на **чекбокс** слева от задачи

### Автоматический rollover:
- Незавершённые задачи из прошедших дней автоматически вернутся в пул при следующем открытии приложения
